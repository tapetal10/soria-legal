Privacy Policy

Last updated: November 2026

1. Data controller

Soria Shorts is a personal application used exclusively by its owner. The data controller is the owner of the TikTok/YouTube accounts on which content is published.

2. Data collected

No personal data is collected, stored on any server, or shared with third parties. The application runs locally on the owner's machine. The only external identifiers used are the API access tokens (TikTok, YouTube, LLM providers) entered by the owner, stored locally in a .env file that never leaves the machine.

3. Data accessed via TikTok API

Through the Content Posting API, the application only accesses the owner's own profile information (display name, avatar, open ID) via user.info.basic, and publishes videos on the owner's account via video.publish. No other user's data is ever accessed.

4. Data retention

Generated videos and state files are stored locally on the owner's machine and can be deleted at any time. Nothing is retained on external servers by the application itself.

5. Your rights

As no personal data is processed beyond the owner's own account activity, GDPR rights (access, deletion, portability) are exercised directly by deleting local files or revoking the app's access in TikTok settings.

6. Contact

For any privacy question: the owner's contact email registered on the TikTok developer account.
